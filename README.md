# FocusLock iOS

> QR code-based phone locking app to boost productivity and reduce screen time

![iOS](https://img.shields.io/badge/iOS-15.0+-blue)
![Swift](https://img.shields.io/badge/Swift-5.9-orange)
![SwiftUI](https://img.shields.io/badge/SwiftUI-3.0-green)

##  Overview

FocusLock helps users stay focused by physically locking their phone using QR codes placed at specific locations. Unlike timer-based apps, you must return to the physical location to unlock.

##  Features

- [ ] Generate unique QR codes for lock points
- [ ] Scan QR codes to lock/unlock device
- [ ] Block distracting apps using Screen Time API
- [ ] Multiple lock point support
- [ ] Usage analytics
